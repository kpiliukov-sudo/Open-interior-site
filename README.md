# Floating Layer / Сайт-поле из 12 фотографий

Этот репозиторий — экспериментальный сайт-слой с 12 плавающими фотографиями, каждая из которых является активной ссылкой.

## Идея

- На экране всегда находится 12 изображений.
- Каждая фотография — отдельный объект, плавающий по странице.
- Изображения кликабельны и ведут на разные разделы/проекты.

## Текущее состояние

Сейчас в проекте создаётся базовая структура:
- `index.html` — главная страница
- `style.css` — стили
- `script.js` — логика движения и появления фотографий
